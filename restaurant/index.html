    Data backup & restore

    Back up the complete local ledger, settings and images. Save the file in a shared device folder. Shared-folder backups remain after uninstall. After reinstall, reconnect that folder to discover your backups and recover the saved ledger.

    Uninstall-safe backups

    Choose a shared backup folder to enable automatic backups.

    Use a folder such as Documents / Restaurant Backups, outside Android/data. Reinstalling requires granting folder access again. Keep an additional copy on another device.

    80 mm receipt printing

    Uses Android’s print dialog. Select ESC POS USB Print Service and the tested 80 mm printer. Submitted jobs still require checking paper output; reprint a saved bill after a printer problem.
